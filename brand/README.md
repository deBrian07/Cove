# Cove brand kit

This folder contains **individual production assets**, separated by file type/use. It matches the blue coastal-wave C direction you approved, not the earlier violet or nested-C concepts.

| Folder | Contents |
|---|---|
| `00_Previews` | Approved reference board and an at-a-glance inventory |
| `01_Logos` | Wave C symbol, horizontal/stacked wordmarks, transparent SVGs and PNGs, monochrome versions |
| `02_App_Icons` | Mac app icon light/dark variants, SVG source, `.icns`, full `.iconset` |
| `03_Favicons` | Transparent favicon PNG sizes and multi-resolution `.ico` |
| `04_Social` | Light/dark GitHub banners, Open Graph social preview, avatar |
| `05_Guidelines` | Typography, spacing, color palette, usage principles |
| `06_Design_Tokens` | CSS variables and JSON for implementation |

Suggested first assets:

- macOS Dock: `02_App_Icons/Cove.icns`
- GitHub README: `01_Logos/Cove-Horizontal-OnLight.svg`
- Website favicon: `03_Favicons/favicon.ico`
- Social preview: `04_Social/Cove-OpenGraph-1200x630.png`
- Colors: `06_Design_Tokens/cove-tokens.css`

All assets in this kit were created for Cove; no font files are included. Source SVGs are editable. The vector mark was recreated from the approved presentation image, not recovered from an original design file.
